Google Apps Script & Deploying Media Pembelajaran

Konsep dasar Apps Script untuk guru: menghubungkan file HTML interaktif dengan Google Spreadsheet tanpa biaya server, serta mempublikasikan (deploy) web app agar langsung dapat dibuka melalui browser IFP.

AN
Ahmad Nur Andy Pratama, S.Kom.
Arsitek Google Apps Script & Web Deployment
🚀 Langkah Deploying
  • Buka script.google.com > Masukkan file HTML dan Code.gs.
  • Tulis fungsi doGet(e) untuk menyajikan tampilan web.
  • Deploy > New Deployment > Web App > Akses: Anyone.
🌐 Membuka di Layar IFP
  • Cukup ketik tautan web app di browser IFP atau buat QR Code.
  • Simpan ke Bookmark peramban IFP untuk penggunaan harian.

Kode Boilerplate doGet()

🛠️ Panduan Praktik & Pengumpulan Produk Akhir

Sesi praktik langsung untuk mewujudkan media pembelajaran berbasis AI dan gamifikasi yang siap tayang di IFP.

1
11.30–12.15 WIB · 45 Menit (1 JP)

Praktik 1 — Eksplorasi Fitur Hardware & Touch IFP

Tujuan: Memastikan guru terbiasa dengan sensitivitas multi-touch, kanvas whiteboard, alat anotasi mengambang, dan integrasi screen sharing gawai ke IFP.

  • ✓ Sentuhan Stylus Ganda: Praktik menulis materi dengan 2 pena berujung berbeda secara serentak.
  • ✓ Anotasi Dokumen: Buka file PDF materi pelajaran dan beri catatan/lingkaran menggunakan floating tool.
  • ✓ Screen Projection: Uji mirroring layar laptop atau ponsel guru langsung ke IFP tanpa kabel.
2
12.15–13.00 WIB · 45 Menit (1 JP)

Praktik 2 — Produksi Konten Bahan Ajar dengan AI

Tujuan: Menghasilkan paket bahan ajar digital, ilustrasi visual yang tajam untuk layar besar, dan susunan kuis interaktif sesuai mata pelajaran yang diampu.

  • ✓ Prompting Pedagogis: Rumuskan instruksi AI untuk memproduksi materi 1 bab/topik pelajaran.
  • ✓ Aset Gambar 4K: Generate minimal 3 gambar ilustrasi pembelajaran yang jelas di layar 65"-86".
  • ✓ Kuis Interaktif: Susun 5 butir soal pilihan ganda / matching pairs untuk kuis kelas.
3
14.00–14.45 WIB · 45 Menit (1 JP)

Praktik 3 — Gamifikasi & Deploying Google Apps Script

Tujuan: Memasang materi dan aset game ke template HTML, melakukan live deployment di Google Apps Script, dan menguji langsung di browser panel IFP.

  • ✓ Koneksi Template: Masukkan pertanyaan dan gambar hasil AI ke script HTML gamifikasi.
  • ✓ Deploy Web App: Terbitkan proyek ke Apps Script dengan akses publik ('Anyone').
  • ✓ Testing di Layar IFP: Buka URL di browser IFP Hisense dan mainkan kuisnya dengan sentuhan jari!
